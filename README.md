## 核心能力
1. **点对点消息直连**（消息条）
2. **分布式计算聚合**（算力/带宽贡献者）
3. **内容传播**（尤其视频）
4. **低延迟游戏大厅**（跨游戏连线）
5. **话语权回归**（本地优先 + 自愿联网 + 跨平台）
