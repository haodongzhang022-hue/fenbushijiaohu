## 2. 测试矩阵

### 2.1 M2 net-policy（联网策略切换 / NAT 中继兜底）

| 覆盖点 | 结果 | 依据 |
|--------|------|------|
| online + NAT 失败 → relay | ✅ | `shouldUseRelay()=true`，`preferredPath()='relay'` |
| online + NAT 成功 → direct | ✅ | `preferredPath()='direct'` |
| lan → 局域网直连 | ✅ | `preferredPath()='direct'`，可广播 |
| offline → local，不可广播 | ✅ | `preferredPath()='local'`，`canBroadcast()=false` |
| offline 仍可接收回环 | ✅ | 与 M1 core policy 契约一致（`canReceive()=true`） |
| setMode 非法模式抛错 | ✅ | `setMode('hacker-mode')` 抛错 |
| **构造器非法模式校验** | ⚠️ | `new Policy('hacker-mode')` 不抛错，与 setMode 不一致 → **P2-01** |
| relay 中继兜底转发 | ✅ | `forwardVia` 成功、`bytes>0` |
| relay 无可用中继抛错 | ✅ | `requestRelay` 抛「无可用中继节点」 |
| relay 同目标复用链路 | ✅ | `findRelay` 仅调用 1 次 |
