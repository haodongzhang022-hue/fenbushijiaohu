## 2. 二级信息视图（供人类俯瞰）

| 维度 | 内容 |
|------|------|
| 目标 | 分布式用户直连通讯 + 分布式计算 + 内容传播 + 话语权回归 |
| 架构分层 | 通信 / 会话身份 / 数据 / 计算 / 信任策略 / 应用 六层 |
| 关键结论 | ✅ 整体可行；首期做「消息条 P2P 直连」MVP |
| 高风险 | NAT 穿透、恶意计算节点、跨平台协议漂移 |
| 当前阶段 | M0 完成 + M0.5 v2 增量；M1 最小可测代码基（packages/core）已跑通，停在 CP1 |
| 首期范围 | transport + session + identity + policy |
