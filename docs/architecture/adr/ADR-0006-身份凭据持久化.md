# ADR-0006 · 身份凭据本地 Keystore 加密持久化

## 背景
长期身份密钥（Ed25519）需要安全持久化到本地，支持跨会话身份连续性。裸存密钥存在泄露风险，需加密 at-rest。

## 选项
1. **AES-256-GCM 加密 + PBKDF2 口令派生 + 本地持久化**
2. 裸存密钥（无加密）
3. 云端托管密钥

## 决策
**采用本地 Keystore 加密持久化**（AES-256-GCM + PBKDF2 + 状态机）。

## 理由
- 本地优先 + 自愿联网原则：密钥不离开本地。
- AES-256-GCM 提供认证加密，PBKDF2 从口令派生密钥（100k 迭代）。
- 状态机（generated→locked→active→revoked）管理密钥生命周期。
- 与 M6 信誉绑定：长期身份密钥是信誉可累积的前提。

## 否决项
- 裸存密钥泄露风险高，否决。
- 云端托管密钥违背「话语权回归本地」原则，否决。

## 影响
- `packages/core/src/identity/keystore.js` 实现加密持久化。
- 支持 store 注入（内存/文件/浏览器 localStorage）以便测试与多环境。
- 密钥丢失风险通过恢复码/备份机制缓解。
