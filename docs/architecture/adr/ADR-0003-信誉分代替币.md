# ADR-0003 · 采用信誉分代替区块链币

## 背景
分布式计算需要激励节点贡献算力/带宽。常见方案为引入区块链代币或积分经济。需要决策激励机制的技术选型。

## 选项
1. **信誉分**（单向棘轮 + 行为分 + 时间衰减 + 共识锚定）
2. 区块链代币（ERC-20 或自定义链）
3. 无激励（纯志愿）

## 决策
**采用信誉分代替区块链币**，不做代币经济。

## 理由
- 规避经济与监管复杂度（代币涉及合规、交易所、KYC）。
- 信誉分绑定长期身份密钥，可累积、可防刷，更契合「话语权回归」理念。
- 实现成本低，单向棘轮防刷分机制已在 M3/M6 中落地验证。

## 否决项
- 区块链代币引入经济复杂度、合规风险、资源消耗，否决。
- 无激励模式下节点贡献意愿低，难以形成规模，否决。

## 影响
- 信誉分模块落地于 `packages/compute/src/reputation.js` 与 M6 治理模块。
- 防刷分机制（单向棘轮/冷启动保护/举报权重）为后续治理设计提供基础。
