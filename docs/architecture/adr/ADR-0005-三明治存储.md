id: ADR-0005
title: 采用「本地热存 + 云端热存 + 115 冷存」三明治存储
status: accepted
date: 2025-08-25
owner: dongjiagoushi
decision: 本地热存（快速读）→ 云端热存（跨端同步）→ 115 冷存（加密归档防丢失）三层存储体系
rationale: |
  - 本地优先：核心数据先落本地
  - 云端同步：签名账本增量同步（CloudSync）
  - 115 冷存：AES-256-GCM 加密归档，定位"防丢失"而非"热读"
  - 签名账本 + Lamport 时钟保证多端最终一致
consequences: |
  - 需要 CloudSync（append-only 签名账本 + 增量推送/拉取）
  - 需要 Archive115（加密归档 + 恢复 + 定期调度）
  - 115 需处理 OAuth 授权/配额/速率限制
  - 冷存数据不可明文读取（加密）
alternatives:
  - 纯本地存储：多端不同步
  - 纯云端存储：本地优先原则被破坏
refs: [09-审查补充与增强, 16-M4bM5M6与传输层设计, packages/content/src/sync.js, packages/content/src/archive.js]
