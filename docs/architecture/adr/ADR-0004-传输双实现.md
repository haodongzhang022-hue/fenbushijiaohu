---
id: ADR-0004
title: 传输层采用 WebRTC + libp2p 双实现，统一 Transport 抽象
status: accepted
date: 2025-08-25
owner: dongjiagoushi
decision: 浏览器端用 WebRTC（DTLS 加密），Node/服务端用 libp2p（Noise 加密），通过统一 Transport 接口可插拔切换
rationale: |
  - 浏览器原生支持 WebRTC，无需额外插件
  - libp2p 适合 Node 守护进程/桌面端
  - 统一接口保证业务层不感知底层实现差异
  - NAT 穿透：STUN + TURN 兜底，relay-mesh 容错
consequences: |
  - 需要实现 WebRTCTransport 和 Libp2pTransport 两个适配器
  - 需要 createTransport 工厂按环境选择实现
  - NAT 穿透失败时降级到 relay-mesh
  - 内存模拟（MemoryTransport）用于测试
alternatives:
  - 仅 WebRTC：Node 端不适用
  - 仅 libp2p：浏览器不适用
refs: [16-M4bM5M6与传输层设计, packages/core/src/transport]
---
