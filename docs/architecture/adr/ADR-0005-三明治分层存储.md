# ADR-0005 · 三明治分层存储（本地热存 + 云端 + 115 冷存）

## 背景
内容传播（尤其视频）需要可靠的存储保障。单点本地存储存在丢失风险，需要构建多级备份体系。同时 115 网盘具有低成本大容量特性，可作为冷存归档层。

## 选项
1. **三明治分层存储**：本地热存（L0）→ 云端热存（L1）→ 115 冷存（L2）
2. 仅本地存储（无备份）
3. 仅云端存储（依赖中心化服务）
4. 全量上区块链（成本不可行）

## 决策
**采用三明治分层存储**：本地热存 + 云端增量同步 + 115 加密冷存归档。

## 理由
- 本地优先原则：数据先落本地，再按策略同步。
- 云端增量同步支持多端收敛（签名账本 + Lamport 时钟）。
- 115 定位「防丢失」冷存，加密归档后定期上传，不依赖其在线性。
- 规避 R-115-限制 [HIGH]：115 仅授权归档后端，非在线存储。

## 否决项
- 仅本地存储无法防设备丢失/损坏。
- 仅云端存储违背「话语权回归本地」理念。
- 区块链存储成本不可行。

## 影响
- `packages/content/src/sync.js` 实现 CloudSync 增量同步。
- `packages/content/src/archive.js` 实现 Archive115 加密冷存归档。
- 事实源 = 本地签名账本（append-only）。
