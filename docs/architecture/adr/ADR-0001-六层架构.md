  - 下层稳定（传输/会话），上层可插拔（应用）
  - 信任策略横切所有层（授权 + 信誉）
  - 应用层可独立演进（游戏大厅/联邦协议）

  - 新增能力需落到对应层，不跨层
  - 层间接口需显式契约（见 04 号文档）
  - 上层依赖下层，下层不反向依赖上层

# ADR-0001 · 采用六层分层架构

## 背景
分布式交互体系需要一套清晰的分层架构来指导开发。

## 决策
采用「通信 / 会话身份 / 数据 / 计算 / 信任策略 / 应用」六层分层架构。

## 影响
- 各层独立演进，通过接口契约交互
- 信任策略为横切关注点，贯穿所有层
