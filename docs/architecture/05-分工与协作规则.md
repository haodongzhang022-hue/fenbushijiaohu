## 2. 协作/接力规则
1. **契约先行**：所有跨模块交互以 `protos/*` 契约为准，改动需先改契约。
2. **模块独立可测**：每个模块有独立单测，接口 mock 先行。
3. **状态强制标注**：任务统一带 `todo / in_progress / blocked / failed / done`。
4. **风险显式上报**：任何 `blocked / failed` 必须记录原因，不吞异常。
5. **CP 暂停确认**：跨里程碑放行需人在 CP 点确认（见 06 进度对齐）。

---

## 3. 传消息规则（异步协作）
- 架构师发布契约 → 各工程师认领 → 实现 → 提交 PR → 架构师评审接口是否符合契约。
- 任何接口变更走 `protos` 契约 + 版本号（v1/v2），不允许隐性破坏。
