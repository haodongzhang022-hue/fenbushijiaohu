## 3. 风险升级路径

1. **发现风险** → 登记到本文件（id/等级/描述/触发阈值）
2. **自动缓解** → 对应模块实现缓解方案（代码/配置）
3. **触发阈值达到** → 标记为「已触发」，上报人工决策
4. **人工拍板** → 确定继续/降级/终止方案
5. **复盘记录** → 沉淀到 08-汇报与复盘

> 所有风险显式暴露，不兜底、不忽略。风险承担主体为人类（张浩东），开发团队只负责规避与上报。
